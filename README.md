Unity 6000.2.6f2

A top-down shooter game. Developed (constantly) by myself. Download the latest build from the Releases section or https://nosteboste.itch.io/

What can you do when you're suddenly alone with hordes of orcs? Only one thing - killem all!

Controls:
W/S - move
A/D - turn
LMB - fire
P - pause
